# CS2-and-CSGO-Simplify-Viewmodel-Settings

<p>Simple way to modify ur viewmodel/hands</p>
<br>
<p>Download the config and put it: <pre>...\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg</pre></p>

<h3>Check values:</h3>
<blockquote>
  <b>VInfo</b> - <code>to get MAIN current settings</code>
  <br>Add <b>V</b> to command to get current value
</blockquote>
<h3>The Settings:</h3>
<blockquote>
  <i>Vx</i> - <code>(-2 to 2.5) [+0.5 or -0.5 only] OR use Min & Max (HxMIN/MAX)</code>
  <br><i>Vy</i> - <code>(-2 to 2) [+0.5 or -0.5 only] OR use Min & Max (HyMIN/MAX)</code>
  <br><i>Vz</i> - <code>(-2 to 2) [+0.5 or -0.5 only] OR use Min & Max (HzMIN/MAX)</code>
  <br><i>Vfov</i> - <code>(54 to 68) [+2 or -2 only] OR use Min & Max</code>
  <br><i>VPreset</i> - <code>(0 / 1) choosing presets</code>
  <br><i>V</i> - <code>(1 to 4) custom presets</code>
</blockquote>
Now you can create your own preset!
<br>
<h3>Instruction:</h3>
<blockquote>
  Write <code>VInfoV</code>, you will get the values of commands.
  <br>Now open SVmS.cfg in notepad.
  <br>Duplicate string <code>Alias V4 "VfovMIN; Vx-2; Vy-2; Vz-2"; </code>.
  <br>Now change <code>"VfovMIN; Vx-2; Vy-2; Vz-2"</code> to your values.
  <br>Also change <code>V4</code> to new number (<code>V5</code>)
  <br>In CS2 write again <code>exec SVmS</code> to update.
</blockquote>
<h3>DONE!</h3>
